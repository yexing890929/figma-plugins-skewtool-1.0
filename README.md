# Skew Tool（本地开发版）

这是一个 Figma 斜切插件的最小可运行版本：选择一个或多个未斜切的普通图层，选择九宫格锚点并输入水平和垂直斜切角度，然后应用。

## 在 Figma 中运行

1. 打开 Figma Desktop，进入任意 Design 文件。
2. 选择 `Plugins` → `Development` → `Import plugin from manifest…`。
3. 选择本项目的 `manifest.json`。
4. 选中一个矩形或 Frame，运行 `Plugins` → `Development` → `Skew Tool`。

## 当前边界

- 支持：普通图层、多选、已有旋转的图层、九宫格锚点、每轴 `±15° / ±30° / ±45°` 斜切预设、水平/垂直斜切、会话内撤销与重置。
- 九宫格锚点决定图层哪一点保持固定；默认中心锚点，切换锚点会立即更新画布预览。
- 每组轴向预设仅修改对应的水平或垂直角度，并同步输入、滑杆与画布预览；手动调整角度会更新对应预设高亮。
- 支持继续调整打开插件前已有斜切的图层：角度表示相对本次会话初始形状新增的斜切，`0°` 保持原有形状；不会读取或反推原有斜切角度。Reset 恢复本次会话初始形状。
- 暂不支持：Auto Layout 中由布局控制位置的子项、整体群组斜切。
- 点击“撤销上一步”会还原最后一次点击“应用斜切”前的状态；“重置本次会话”会还原插件打开后首次修改前的状态。
- 角度限制：`-60°` 到 `60°`，以避免变换矩阵接近退化。
